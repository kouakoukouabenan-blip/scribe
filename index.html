      Comment obtenir une clé
      1. Touche Obtenir une clé : Google AI Studio s'ouvre. Connecte-toi avec ton compte Google.
      2. Touche Create API key (« Créer une clé API »). Si Google demande un projet, choisis-en un ou laisse-le en créer un.
      3. Touche la clé pour la copier : elle commence par AIza.
      4. Reviens ici, colle-la dans le champ « Clé API Gemini », puis touche Tester la connexion.

      Google applique ses propres quotas et conditions à ces clés : vérifie-les sur AI Studio si tu dictes beaucoup.

      Si Google retire le modèle, l'appli en cherche un autre toute seule. « Détecter » force cette recherche.

      « Auto » suit le réglage de ton téléphone.
